# Animal Feast (Snake Game)

A fun, interactive twist on the classic Snake game built with **Python** and **Pygame**. Players can choose different animal avatars, each hunting for their favorite food!

## Features

- **Animal Selection Menu**: Choose between 6 unique animals with live visual previews.
- **Animal & Favorite Food Pairing**:
  - **Rabbit** $\rightarrow$ Crunchy Carrots
  - **Tiger** $\rightarrow$ Fresh Meat
  - **Panda** $\rightarrow$ Sweet Sugar Cane / Bamboo
  - **Monkey** $\rightarrow$ Bananas
  - **Penguin** $\rightarrow$ Fish
  - **Snake** $\rightarrow$ Crisp Apples
- **Custom Pixel Art & Graphics**: Procedural rendering of animal heads (ears, beaks, stripes, tongues) and detailed food icons.
- **Polished Gameplay**: Top HUD with score & animal info, smooth controls with rapid keypress protection, game-over recap, and restart options.

## Controls

| Action | Controls |
| :--- | :--- |
| **Move** | Arrow Keys (`↑`, `↓`, `←`, `→`) or `W`, `A`, `S`, `D` |
| **Select Animal (Menu)** | `↑` / `↓` or Number Keys `1`–`6` or Mouse Click |
| **Start / Play** | `Enter` or `Space` |
| **Change Animal (In-Game / Over)** | `C` or `M` |
| **Restart (Game Over)** | `R` |
| **Quit** | `Q` or `ESC` |

## Getting Started

### Prerequisites

- Python 3.10+
- Pygame (`pip install pygame`)

### Running the Game

Launch using Python:
```bash
python main.py
```
Or double-click `run_game.bat` on Windows.
